# Maze Algorithm Solver & Generator

A professional Java-based application designed to generate complex mazes and solve them using efficient pathfinding algorithms.

## Features 

- **Maze Generation:** Uses the **Depth-First Search (DFS)** algorithm to create perfect, unsolvable-loop-free mazes.
- **Smart Solver:** Implements a pathfinding algorithm to find the shortest route from start to finish.
- **Real-time Visualization:** - Mazes are rendered in the console using `#` for walls.
  - Solved paths are clearly marked with the `*` symbol.
- **State Management:** Ability to reset and re-run the solver on the same maze structure.

## Technologies

- **Language:** Java 17+
- **Version Control:** Git
- **Architecture:** Object-Oriented Programming (OOP)

## How to Run 

1. **Prerequisites:** Make sure you have [JDK 17](https://www.oracle.com/java/technologies/downloads/) or newer installed.
2. **Clone the repository:**
  ```bash
  git clone https://github.com/Wacpaan/maze-algorithm-solver.git
  ```
3. **Navigate to the project directory:** 
  ```bash 
  cd maze-algorithm-solver
  ```
4. **Compile and run: ** 
  ```bash
  javac src/main/java/com/maze/App.java
  java src/main/java/com/maze/App
  ```
