# Maze Algorithm Solver & Generator

A professional Java-based application designed to generate complex mazes and solve them using efficient pathfinding algorithms. This project was developed as part of an engineering thesis to demonstrate algorithmic logic and data structure implementation.

## Features 

- **Maze Generation:** Uses the **Depth-First Search (DFS)** algorithm to create perfect, unsolvable-loop-free mazes.
- **Smart Solver:** Implements a pathfinding algorithm to find the shortest route from start to finish.
- **Real-time Visualization:** - Mazes are rendered in the console using `#` for walls.
  - Solved paths are clearly marked with the `*` symbol.
- **State Management:** Ability to reset and re-run the solver on the same maze structure.

## Technologies

- **Language:** Java 17+
- **Version Control:** Git
- **Architecture:** Object-Oriented Programming (OOP)
